# Mercado Bom Vizinho

O Mercado Bom Vizinho é um MVP desenvolvido para apoiar a organização das atividades de um estabelecimento comercial da comunidade.

## Objetivo

O sistema tem como objetivo facilitar o cadastro de produtos e o controle das movimentações de estoque, permitindo registrar entradas e saídas de forma simples e organizada.

## Tecnologias planejadas

- Python
- Flask
- Jinja2
- SQLAlchemy
- SQLite
- Pytest

## Arquitetura

O projeto utiliza uma arquitetura monolítica em camadas, separando apresentação, regras de negócio e persistência de dados.

## Funcionalidades do MVP

- Cadastro de produtos;
- Listagem de produtos;
- Registro de entradas de estoque;
- Registro de saídas de estoque;
- Validação da quantidade disponível;
- Histórico de movimentações.

## Status

MVP em desenvolvimento.
